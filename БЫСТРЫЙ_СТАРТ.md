# ⚡ Быстрый старт Tez Jumush

## 🚀 Для тех, кто уже все установил

### Запуск в 3 команды:

```bash
# 1. Запуск backend (в одном терминале)
cd backend
python main.py

# 2. Запуск frontend (в другом терминале)
cd frontend
npx expo start

# 3. Сканируйте QR код в Expo Go
```

## 📋 Быстрая проверка установки

```bash
# Проверьте все зависимости одной командой:
node --version && python --version && git --version && expo --version
```

Должно показать версии всех программ без ошибок.

## 🔧 Быстрое исправление проблем

### Backend не запускается:
```bash
cd backend
pip install -r requirements.txt
python main.py
```

### Frontend не запускается:
```bash
cd frontend
npm install
npx expo start --clear
```

### База данных не подключается:
1. Проверьте PostgreSQL запущен
2. Проверьте пароль в `backend/.env`
3. Создайте базу `tez_jumush` в pgAdmin

### Expo Go не подключается:
```bash
# Попробуйте с туннелем:
npx expo start --tunnel
```

## 🎯 Полезные команды

### Очистка кэша:
```bash
# Frontend
cd frontend
npm start -- --reset-cache

# Или
npx expo start --clear
```

### Переустановка зависимостей:
```bash
# Frontend
cd frontend
rm -rf node_modules package-lock.json
npm install

# Backend
cd backend
pip uninstall -r requirements.txt -y
pip install -r requirements.txt
```

### Просмотр логов:
```bash
# Backend логи в терминале
# Frontend логи - встряхните телефон в Expo Go
```

## 🔄 Перезапуск всего проекта
