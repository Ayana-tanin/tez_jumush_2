# 🚀 Полный гайд по запуску Tez Jumush для новичков

## 📋 Что мы будем делать

В этом гайде мы пошагово настроим и запустим мобильное приложение Tez Jumush на вашем компьютере. В итоге вы сможете:
- Просматривать приложение на своем телефоне через Expo Go
- Редактировать код и видеть изменения в реальном времени
- Тестировать все функции приложения

## 🛠 Что нужно установить

### 1. Установка IDE (редактора кода)

**Visual Studio Code** - это бесплатный редактор кода от Microsoft.

**Скачивание и установка:**
1. Перейдите на сайт: https://code.visualstudio.com/
2. Нажмите кнопку "Download for Windows" (или вашу ОС)
3. Запустите скачанный файл и следуйте инструкциям установки
4. При установке отметьте галочки:
   - ✅ "Add to PATH"
   - ✅ "Register Code as an editor for supported file types"

**Полезные расширения для VS Code:**
После установки откройте VS Code и установите расширения:
1. Нажмите `Ctrl+Shift+X` (Extensions)
2. Найдите и установите:
   - **ES7+ React/Redux/React-Native snippets** - для React Native
   - **Prettier - Code formatter** - для форматирования кода
   - **Auto Rename Tag** - для HTML/JSX тегов
   - **Bracket Pair Colorizer** - для цветных скобок

### 2. Установка Node.js

**Node.js** - это среда выполнения JavaScript, нужна для работы с React Native.

**Установка:**
1. Перейдите на сайт: https://nodejs.org/
2. Скачайте **LTS версию** (рекомендуемая)
3. Запустите установщик и следуйте инструкциям
4. Проверьте установку:
   - Откройте командную строку (`Win+R`, введите `cmd`)
   - Введите: `node --version`
   - Должна появиться версия Node.js (например, v18.17.0)

### 3. Установка Git

**Git** - система контроля версий для скачивания проекта.

**Установка:**
1. Перейдите на сайт: https://git-scm.com/
2. Скачайте Git для Windows
3. При установке оставьте все настройки по умолчанию
4. Проверьте установку:
   - В командной строке введите: `git --version`

### 4. Установка Python

**Python** - нужен для работы backend части приложения.

**Установка:**
1. Перейдите на сайт: https://www.python.org/downloads/
2. Скачайте последнюю версию Python 3.x
3. **ВАЖНО:** При установке отметьте галочку "Add Python to PATH"
4. Проверьте установку:
   - В командной строке введите: `python --version`

### 5. Установка PostgreSQL

**PostgreSQL** - база данных для хранения информации приложения.

**Установка:**
1. Перейдите на сайт: https://www.postgresql.org/download/windows/
2. Скачайте PostgreSQL installer
3. При установке:
   - Запомните пароль для пользователя `postgres`
   - Порт оставьте 5432
   - Locale выберите "Russian, Russia"
4. После установки запустите pgAdmin (должен появиться в меню Пуск)

### 6. Установка Expo CLI

**Expo CLI** - инструмент для разработки React Native приложений.

**Установка:**
1. Откройте командную строку как администратор
2. Введите команду: `npm install -g @expo/cli`
3. Дождитесь завершения установки
4. Проверьте: `expo --version`

### 7. Установка Expo Go на телефон

**Expo Go** - приложение для просмотра вашего проекта на телефоне.

**Для Android:**
1. Откройте Google Play Store
2. Найдите "Expo Go"
3. Установите приложение

**Для iOS:**
1. Откройте App Store
2. Найдите "Expo Go"
3. Установите приложение

## 📁 Скачивание проекта

### 1. Создание папки для проектов

1. Создайте папку на диске C: `C:\Projects`
2. Откройте эту папку в проводнике

### 2. Клонирование проекта

1. Откройте командную строку в папке Projects:
   - В проводнике нажмите в адресной строке
   - Введите `cmd` и нажмите Enter
2. Введите команду для клонирования:
   ```bash
   git clone https://github.com/your-username/tez-jumush.git
   ```
   (Замените на актуальную ссылку на ваш репозиторий)
3. Перейдите в папку проекта:
   ```bash
   cd tez-jumush
   ```

### 3. Открытие проекта в VS Code

1. В командной строке введите:
   ```bash
   code .
   ```
2. VS Code откроется с вашим проектом

## ⚙️ Настройка проекта

### 1. Настройка базы данных

**Создание базы данных:**
1. Откройте pgAdmin
2. Подключитесь к серверу (введите пароль postgres)
3. Правый клик на "Databases" → "Create" → "Database"
4. Имя базы: `tez_jumush`
5. Нажмите "Save"

### 2. Настройка переменных окружения

**Backend настройки:**
1. В VS Code откройте файл `backend/.env`
2. Если файла нет, создайте его и добавьте:
   ```env
   # База данных
   DATABASE_URL=postgresql://postgres:ВАШ_ПАРОЛЬ@localhost:5432/tez_jumush
   
   # Безопасность
   SECRET_KEY=your-super-secret-key-here-make-it-long-and-random
   ALGORITHM=HS256
   ACCESS_TOKEN_EXPIRE_MINUTES=30
   
   # SMS (для разработки можно оставить пустыми)
   TWILIO_ACCOUNT_SID=your_account_sid
   TWILIO_AUTH_TOKEN=your_auth_token
   TWILIO_PHONE_NUMBER=+1234567890
   
   # Файлы (для разработки можно оставить пустыми)
   CLOUDINARY_CLOUD_NAME=your_cloud_name
   CLOUDINARY_API_KEY=your_api_key
   CLOUDINARY_API_SECRET=your_api_secret
   ```
3. Замените `ВАШ_ПАРОЛЬ` на пароль от PostgreSQL

**Frontend настройки:**
1. Откройте файл `frontend/.env`
2. Если файла нет, создайте его и добавьте:
   ```env
   EXPO_PUBLIC_API_URL=http://localhost:8000
   EXPO_PUBLIC_GOOGLE_CLIENT_ID=your_google_client_id
   ```

### 3. Установка зависимостей

**Backend зависимости:**
1. Откройте терминал в VS Code (`Ctrl+` ` `)
2. Перейдите в папку backend:
   ```bash
   cd backend
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

**Frontend зависимости:**
1. Откройте новый терминал (`Ctrl+Shift+` ` `)
2. Перейдите в папку frontend:
   ```bash
   cd frontend
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```

## 🚀 Запуск проекта

### 1. Запуск Backend (API сервера)

1. В терминале backend папки введите:
   ```bash
   python main.py
   ```
2. Вы должны увидеть сообщение:
   ```
   INFO:     Uvicorn running on http://0.0.0.0:8000
   ```
3. Откройте браузер и перейдите на http://localhost:8000
4. Вы должны увидеть: `{"message": "Tez Jumush API работает!"}`

### 2. Запуск Frontend (мобильного приложения)

1. В терминале frontend папки введите:
   ```bash
   npx expo start
   ```
2. Дождитесь запуска Metro bundler
3. Вы увидите QR код в терминале

### 3. Просмотр на телефоне

**Подключение к одной сети:**
1. Убедитесь, что компьютер и телефон подключены к одной Wi-Fi сети

**Сканирование QR кода:**
1. Откройте Expo Go на телефоне
2. Нажмите "Scan QR code"
3. Отсканируйте QR код из терминала
4. Приложение начнет загружаться на телефоне

## 🔧 Возможные проблемы и решения

### Проблема: "command not found" или "не является внутренней командой"

**Решение:**
1. Перезагрузите компьютер
2. Проверьте, что все программы добавлены в PATH
3. Переустановите программу с галочкой "Add to PATH"

### Проблема: Ошибка подключения к базе данных

**Решение:**
1. Проверьте, что PostgreSQL запущен (в диспетчере задач)
2. Проверьте пароль в файле `.env`
3. Убедитесь, что база данных `tez_jumush` создана

### Проблема: Expo Go не может подключиться

**Решения:**
1. Проверьте Wi-Fi соединение
2. Попробуйте запустить с туннелем:
   ```bash
   npx expo start --tunnel
   ```
3. Отключите антивирус/файрвол временно

### Проблема: Ошибки при установке npm пакетов

**Решение:**
1. Очистите кэш:
   ```bash
   npm cache clean --force
   ```
2. Удалите node_modules и переустановите:
   ```bash
   rm -rf node_modules
   npm install
   ```

### Проблема: Python модули не найдены

**Решение:**
1. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```
